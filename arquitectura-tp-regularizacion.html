01 · Implementado

Regresión Softmax

  1. EntradaVector estandarizado · d features
  2. Capa linealLinear(d, 20) · 0 capas ocultas
  3. Salida20 logits · argmax para predecir

Entrenamiento

Los logits y las etiquetas entran a CrossEntropyLoss. Adam actualiza los pesos con un learning rate fijo por ensayo.

Búsqueda y evaluación

Optuna ejecuta 15 ensayos de 5 épocas y compara la accuracy final de validación. El reentrenamiento usa todo el train oficial y registra métricas del test por época.

02 · Propuesta

MLP con dos capas ocultas

  1. EntradaVector estandarizado · d features
  2. Oculta 1Linear(d, h₁)
    BatchNorm opcional → ReLU → Dropout opcional
  3. Oculta 2Linear(h₁, h₂)
    BatchNorm opcional → ReLU → Dropout opcional
  4. Salida linealLinear(h₂, 20) · 20 logits · argmax para predecir

h₁ y h₂ representan los anchos de las capas. ReLU y la ubicación de BatchNorm y Dropout son ilustrativas.

Loss y optimizador

CrossEntropyLoss + penalización opcional L1, L2 o L1+L2 sobre los pesos. Adam + CLR actualiza los pesos y ajusta el learning rate después de cada batch.

Comparación de regularizadores

Usar validación para comparar accuracy, loss, curvas, pesos y tiempos frente al MLP base. Reservar el test oficial para la evaluación final.
